EX\_13JUN - Cinema Ticket Booking System

Build a simple cinema booking tool. Tasks:

\-> Data setup:

&#x20;- Create a list of movies, where each movie is a tuple: (title, genre, duration\_minutes, ticket\_price)

&#x20;- Add at least 5 movies with varied genres and prices.

The program should:

\-> Display all movies with a numbered list using enumerate()

\-> Ask the user how many tickets they want to buy (they can pick different movies each time)

&#x20;- Each time, ask which movie number and how many tickets

\-> Apply a discount rule using a list comprehension:

&#x20;- If a movie is longer than 120 minutes → 10% discount on that ticket

&#x20;- Build a list of final prices after applying discounts where relevant

\-> Show a booking summary:

&#x20;- List each booked movie with its final price per ticket and quantity

&#x20;- Show the total cost

&#x20;- Show the longest movie they booked (by duration)
