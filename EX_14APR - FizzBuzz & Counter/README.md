EX\_14APR - FizzBuzz \& Counters

Write a program that prints numbers from 1 to 50, but:

&#x20;- If the number is divisible by 3, print "Fizz" instead

&#x20;- If the number is divisible by 5, print "Buzz" instead

&#x20;- If it's divisible by both 3 and 5, print "FizzBuzz"

&#x20;- Otherwise, just print the number

&#x20;- Collect only the plain numbers (the ones that weren't Fizz/Buzz/FizzBuzz) that are greater than 10 into a list and print their sum at the end

&#x20;- Print how many numbers said "Fizz", how many said "Buzz", and how many said "FizzBuzz"
