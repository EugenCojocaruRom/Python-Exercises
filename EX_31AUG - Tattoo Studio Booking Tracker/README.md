EX\_31AUG - Tattoo Studio Booking Tracker

Build a program that:

&#x20;- Asks how many bookings to log today.

&#x20;- For each booking, collects: artist name, tattoo size (Small / Medium / Large), and price ($).

&#x20;- Store each booking as a tuple in a list.

&#x20;- Print a numbered list of all bookings using enumerate() (start at 1) — e.g. 1. Artist: Mara | Size: Medium | Price: $80.

&#x20;- Use a list comprehension to find all Large tattoos and print how many there were (with singular/plural wording — "1 large tattoo" vs "3 large tattoos").

&#x20;- Calculate and print the total revenue for the day.

&#x20;- Find and print the most expensive booking — handle ties if more than one booking shares the top price.



Bonus (optional): aggregate total revenue per artist using a dictionary, then print a leaderboard sorted from highest to lowest earner.
