EX\_29APR - Duplicate Cleaner

You have a list of names where some appear more than once. Your job is to:

&#x20;- Remove duplicates — keep only the first occurrence of each name

&#x20;- Capitalize each name properly (first letter uppercase, rest lowercase)

&#x20;- Sort the result alphabetically

&#x20;- Print each name with its position number (starting from 1)
