EX\_07AUG - Car Wash Service Queue Tracker

You're tracking cars going through a car wash. Each car has a license plate and a wash type: "Basic" ($10), "Deluxe" ($20), or "Premium" ($35).



Core tasks:

&#x20;- Using enumerate() starting at 1, print a numbered queue list showing each car's plate, wash type, and price.

&#x20;- Calculate and print the total revenue for all cars in the queue.

&#x20;- Use a list comprehension to build a list of plates for cars that got a "Premium" wash.

&#x20;- Print how many Premium washes there were, with correct singular/plural wording ("1 Premium wash" vs "3 Premium washes").



Bonus:

&#x20;- Find the most common wash type using max() with a lambda (or a dictionary count).

&#x20;- Add a loyalty discount: if a plate appears more than once in the list, apply 10% off their second+ wash.
