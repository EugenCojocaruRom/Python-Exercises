EX\_23JUN - Birthday Reminder

You have a list of people with their birthdays (month and day). Write a program that:

&#x20;- Stores a list of people, each with a name, birth month, and birth day (you can hardcode it, or — knowing you — take user input instead 😉)

&#x20;- Uses enumerate() to print a numbered list of everyone, formatted like:



&#x20;  1. Alice - 03/15

&#x20;  2. Bogdan - 11/02

&#x20;  3. Cristina - 07/22



&#x20;- Uses a list comprehension to build a new list containing only the people whose birthday is in a specific month (ask the user which month, or hardcode one to start)

&#x20;- Prints how many people have birthdays in that month, and their names



Bonus ideas:

&#x20;- Sort the filtered list by day using sorted() with a lambda

&#x20;- Find the next upcoming birthday from today's date

&#x20;- Add input validation so the month has to be 1–12
