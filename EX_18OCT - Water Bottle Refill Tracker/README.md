EX\_18OCT - Water Bottle Refill Tracker

Scenario: You’re tracking how much water you drink during the day. Each entry is a bottle size in milliliters.



&#x09;bottles = \[500, 250, 750, 330, 500, 1000, 250]



Tasks:

&#x20;- Use enumerate() (starting at 1) to print each bottle like this:

&#x09;Bottle 1: 500 ml

&#x20;- Calculate and print the total in liters (e.g., Total: 3.58 liters). Round to 2 decimals.

&#x20;- Use a list comprehension to create a list of only the “large” bottles (500 ml or more), and print it.

&#x20;- Print how many bottles were smaller than 500 ml.

&#x20;- Check the daily goal of 2.5 liters:

&#x09;If the total is at least the goal, print Goal reached!

&#x09;Otherwise, print how many milliliters are still missing, e.g. Still need 300 ml



Bonus (optional): Change the list so the total is below 2.5 liters and check that the “missing” message works correctly.
