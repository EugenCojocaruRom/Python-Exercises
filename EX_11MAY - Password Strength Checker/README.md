EX\_11MAY - Password strength checker

Write a Python program that checks how strong a password is.

The program should:

&#x20;- Ask the user to enter a password

&#x20;- Check the following rules and keep track of which ones pass:

&#x20;  -> At least 8 characters long

&#x20;  -> Contains at least one number (0–9)

&#x20;  -> Contains at least one uppercase letter

&#x20;  -> Contains at least one special character from this list: !@#$%^\&\*

&#x20;- Collect all the rules that the password fails

&#x20;- Print the failed rules (if any), and then rate the password:

&#x20;  -> 4/4 rules passed -> "Strong password!"

&#x20;  -> 2–3 rules passed -> "Medium password"

&#x20;  -> 0–1 rules passed -> "Weak password"
