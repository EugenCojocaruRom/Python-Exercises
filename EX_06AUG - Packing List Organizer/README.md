EX\_06AUG - Packing List Organizer

Build a program to help organize a packing list for a trip.



Requirements:

&#x20;- Let the user enter items repeatedly (item name, weight in kg, category e.g. "clothing"/"electronics"/"toiletries") until they type done

&#x20;- Store each item as a tuple in a list

&#x20;- Print a numbered packing list using enumerate()

&#x20;- Calculate and print the total weight of everything packed

&#x20;- Use a list comprehension to find all heavy items (weight over some threshold, e.g. 2kg)

&#x20;- Use max() with a lambda to find the heaviest item, safely handling an empty list



Bonus (optional):

&#x20;- Aggregate total weight per category into a dictionary, then print a breakdown sorted heaviest category first with sorted()

&#x20;- Add a weight-limit check (e.g. suitcase limit is 20kg) that warns if the total exceeds it
