EX\_15JUN - Daily Step Challenge Tracker

You have a group of friends doing a 7-day step challenge. Your job is to analyze their results.

Tasks:

&#x20;- Print each participant's total steps and daily average (rounded to the nearest whole number).

&#x20;- Using a list comprehension, find all participants whose average is above 9000 steps/day — print them as "on track".

&#x20;- Using enumerate(), print each participant's ranking (1st, 2nd, etc.) sorted by total steps, highest first.

&#x20;- Find the single best day across all participants combined — print who did it, on which day number, and how many steps.
