EX\_29JUL - Ice Cream Shop Order Tracker

An ice cream shop wants to track its orders throughout the day.



Basic requirements:

&#x20;- Ask the user to enter orders one by one (customer name + flavor + number of scoops), until they type "stop".

&#x20;- Display the list of orders using enumerate() (starting at 1), formatted like: 1. Anna - vanilla x2

&#x20;- Calculate the total number of scoops sold that day.

&#x20;- Using a list comprehension, build a list containing only the big orders (e.g. 3 scoops or more) and print it separately.

&#x20;- Figure out which flavor was the most popular of the day (the one with the highest total scoops ordered).



Bonus:

&#x20;- Add a price per scoop (e.g. $2.50) and calculate the total revenue.

&#x20;- Handle the case where the same customer orders more than once — combine their scoops into a single total.

&#x20;- Print a small "leaderboard" of flavors, from best-selling to least-selling.
