EX\_01JUL - Grocery Aisle Organizer

You have a shopping list where each item belongs to a category. Organize the items by aisle and print a numbered list.

Requirements:

&#x20;- Create a dictionary with products and categories

&#x20;- Use a list comprehension to get all the unique categories (aisles) present.

&#x20;- For each aisle, print its name, then list only the items belonging to that aisle, numbered starting at 1 (use enumerate()).

&#x20;- After listing everything, print the total number of items and the aisle with the most items.
