EX\_09APR - Guess the number

Write a program where:

&#x20;- You pick a secret number (set it as a variable, e.g. secret = 7)

&#x20;- The user gets a number of attempts to guess it (e.g. 3)

&#x20;- After each wrong guess, tell them if the secret number is higher or lower

&#x20;- If they guess correctly, print a congratulations message and stop

&#x20;- If they use all 3 attempts without guessing, reveal the secret number
