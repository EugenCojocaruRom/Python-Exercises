EX\_27JUL - Trivia Night Score Tracker

A pub is running a trivia night with several teams competing across multiple rounds.



Requirements:

&#x20;- Ask the user how many teams are playing, then collect each team's name.

&#x20;- Ask how many rounds will be played.

&#x20;- For each round, ask for each team's score in that round (can be 0 or negative if you want to allow point deductions for wrong guesses).

&#x20;- Store everything in a way that makes sense to you (tuples or dict of lists).

&#x20;- Using enumerate(), print a round-by-round recap showing "Round 1:", "Round 2:", etc., with each team's score for that round.

&#x20;- Calculate each team's total score across all rounds.

&#x20;- Use a list comprehension to find all teams with a total score above the average.

&#x20;- Print a final leaderboard sorted from highest to lowest total score.

&#x20;- Announce the winning team (handle a tie gracefully).



Bonus (optional):

&#x20;- Track which team had the single best round (highest score in any one round) and call it out as "Best Round Performance."

&#x20;- Let the host flag a "double points" round that multiplies all scores for that round by 2 before totals are calculated.
