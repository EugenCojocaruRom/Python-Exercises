EX\_24APR - Word Filter

Write a program that takes a list of words and does the following:

&#x20;- Filter the list to only keep words that have more than 4 letters.

&#x20;- Sort the filtered words alphabetically

&#x20;- Loop through the filtered list and print each word with its length next to it.

&#x20;- Check if the total number of filtered words is even or odd, and print a message saying so.
