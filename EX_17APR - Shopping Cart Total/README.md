EX\_17APR - Shopping Cart Total

Write a program that does the following:

&#x20;- You have a list of items in a shopping cart, where each item is a tuple of (name, price, quantity)

Your tasks:

&#x20;- Create a new list called totals that contains the total cost per item (price × quantity).

&#x20;- Print each item name alongside its total cost

&#x20;- Calculate and print the grand total of the cart.

&#x20;- Print either "Stay on budget!" if the grand total is over $15, or "Nice, you saved money!" if it's $15 or under.
