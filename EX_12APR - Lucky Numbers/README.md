EX\_12APR - Lucky Numbers

Have a list of random numbers, e.g.:

&#x09;numbers = \[14, 7, 23, 8, 42, 15, 3, 30, 11, 27, 6, 18]

&#x20;- Create a new list containing only the even numbers from the list.

&#x20;- Print each even number and whether it's "small" (below 15) or "big" (15 and above).

&#x20;- Calculate and print the average of the even numbers.

&#x20;- Find and print the largest even number, without using max().
