EX\_07JUL - Morse Code Translator

Task:

Write a program that converts a short message (letters and spaces only) into Morse code, and can also decode it back.



Requirements:

&#x20;- Create a dictionary mapping each letter A-Z to its Morse code.

&#x20;- Ask the user to type a sentence (letters and spaces only).

&#x20;- Convert it to Morse code, where:

&#x20;  -> Each letter's Morse code is separated by a single space

&#x20;  -> Each word is separated by a slash /

&#x20;- Then decode that Morse code back into the original sentence, to prove it round-trips correctly.

&#x20;- Handle lowercase/uppercase input gracefully (normalize it).
