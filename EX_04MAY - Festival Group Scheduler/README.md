EX\_04MAY - Festival group scheduler

Create a program that helps organize artistic groups for a festival.

Groups are assigned numbers based on square-free numbers (numbers not divisible by any perfect square other than 1, e.g. 1, 2, 3, 5, 6, 7, 10, 11...).

The program reads which group position to find, a delay time in minutes, and a list of planned time slots.

Print the square-free group number, then print all time slots adjusted by adding the delay to each one.
