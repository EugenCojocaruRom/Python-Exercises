EX\_18SEP - Ice Rink Skate Rental Tracker

You're tracking skate rentals at an ice rink for one day.



Task:

&#x20;- Ask the user how many rentals happened today.

&#x20;- For each rental, collect: customer name, skate size, and number of hours rented.

&#x20;- Store each rental as a tuple in a list.

&#x20;- Print a numbered summary of all rentals using enumerate() (start at 1)

&#x20;- Use a list comprehension to find all rentals longer than 2 hours (the "long rentals").

&#x20;- Print how many long rentals there were, handling singular/plural correctly (e.g. "1 long rental" vs "3 long rentals").

&#x20;- Calculate and print the total number of hours rented across all customers.



Optional bonus:

&#x20;- Find the customer who rented skates for the longest time (handle ties — print all of them if there's more than one).

&#x20;- Group total hours rented by skate size, using a dictionary.
