EX\_23SEP - Study Group Formation Assistant



Task:

You have a list of students with their quiz scores. Your job:

&#x20;- Use enumerate() to print each student with a number (starting at 1), like 1. Ana - 85.

&#x20;- Use a list comprehension to create a new list containing only the names of students who scored 70 or above (the "passing" group).

&#x20;- Print how many students passed vs. failed, and the class average score (rounded to 1 decimal).



Bonus: print the name of the student with the highest score (you can use max() with a key).
