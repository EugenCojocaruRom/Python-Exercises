EX\_29SEP - Text Encoder-Decoder

Write a function encode(text) that compresses a string by replacing consecutive repeated characters with the character followed by its count.

Then write decode(text) that reverses it.



Part 1: Encode

&#x20;- Write a function encode(text) that returns the compressed string.



Part 2: Decode

&#x20;- Write a function decode(compressed) that reverses it.



Part 3: Use a list comprehension

&#x20;- Write a function compression\_report(words) that takes a list of words and returns a list of only the words where the encoded version is shorter than the original, using a list comprehension.



Bonus: Check that decode(encode(text)) == text for a few test strings, and print "OK" or "FAIL" for each one.
