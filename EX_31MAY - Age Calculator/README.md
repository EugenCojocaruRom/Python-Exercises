EX\_31MAY - Age calculator

Write a program that asks for a user's birth year and tells them:

&#x20;- How old they are (or will turn) this year

&#x20;- What year they'll turn 100

&#x20;- A list of every decade birthday they'll hit in the future (30, 40, 50... up to 100), with the corresponding year

Requirements:

&#x20;- Use a for loop with range()

&#x20;- Use a list comprehension to build the list of future decade birthdays

&#x20;- Use enumerate() when printing the decade list

&#x20;- Use an if/else to handle invalid input (e.g. birth year in the future or unrealistically old)
