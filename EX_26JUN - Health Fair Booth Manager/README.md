EX\_26JUN - Health Fair Booth Manager

Create a program that helps organize the community health fair by processing booth names and calculating energy efficiency.

For each booth name, reverse only the vowels to create fun display signs (for example, "Vision" becomes "Vesion").

Then calculate an overall energy rating based on total power usage: A for 500W or less, B for 501-1000W, C for 1001-1500W, and D for over 1500W.



The program should read the number of booths, then each booth's name and power usage in watts.

Print each modified booth name on its own line, followed by the energy rating.
