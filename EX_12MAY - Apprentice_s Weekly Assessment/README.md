EX\_12MAY - Apprentice's weekly assessment

Create a program that helps you manage your apothecary apprentice duties.

You'll receive three ingredient measurements (in drams) and a performance score.

First, check if the three measurements form a geometric progression — where each value equals the previous one multiplied by the same ratio.

Print "Geometric" or "Not geometric".

Then calculate your weekly bonus: start with 10 silver coins, multiply by 1.5 if your performance is 80-89, or multiply by 2.0 if it's 90-100.

Print the total bonus amount.
