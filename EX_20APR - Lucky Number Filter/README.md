EX\_20APR - Lucky Number Filter

Have a list of random numbers, e.g.:

&#x09;numbers = \[14, 7, 23, 8, 42, 15, 3, 30, 11, 27, 6, 18]

&#x20;- Create a list of numbers (starting from 1)

&#x20;- Filter the list to keep only numbers that are divisible by 3 or end with the digit 7 (like 7, 17, 27, 37, 47)

&#x20;- Print the filtered list

&#x20;- Print how many numbers made it through

&#x20;- Print the sum of those numbers
