EX\_02JUN - Race Results Analyzer

You are given a list of race times (in seconds).

Tasks:

&#x20;- Print each runner's position and time using enumerate().

&#x20;- Create a new list containing only runners who finished in under 60 seconds using a list comprehension.

&#x20;- Count how many runners finished under 60 seconds.

&#x20;- Find the fastest time.

&#x20;- Calculate the average race time.

Print a message:

&#x20;- "Excellent race!" if the average is below 60.

&#x20;- "Good effort!" otherwise.

Bonus:

&#x20;- Create a list of runner numbers (not times) who finished under 60 seconds.
