EX\_03JUN - Scrabble Score Calculator

Write a function scrabble\_score(word) that takes a word and returns its Scrabble point value.

Each letter has a point value:

&#x20;- 1 pt:  A, E, I, O, U, L, N, S, T, R

&#x20;- 2 pts: D, G

&#x20;- 3 pts: B, C, M, P

&#x20;- 4 pts: F, H, V, W, Y

&#x20;- 5 pts: K

&#x20;- 8 pts: J, X

&#x20;- 10 pts: Q, Z

Requirements:

&#x20;- The function should work with both uppercase and lowercase input

&#x20;- Use a dictionary to store letter values

&#x20;- Use a list comprehension to calculate the score

Bonus: Use enumerate() to also print each letter with its index and score
