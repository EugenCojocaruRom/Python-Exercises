EX\_30APR - Number Sorter

Write a program that:

&#x20;- Creates a list of 10 random numbers between 1 and 100

&#x20;- Filters and finds all the even numbers from that list

&#x20;- Prints each even number, along with whether it's "small" (≤ 50) or "big" (> 50)

&#x20;- Prints the biggest even and odd numbers from the list
