EX\_24SEP - Marathon Bib Number Assigner



A group of runners registers for a marathon in the order they sign up. You need to:



&#x20;- Given a list of runner names (in registration order), assign each one a bib number starting from 101 (so the first runner gets 101, the second 102, etc.). Use enumerate() to do this — don't hardcode the numbers.

&#x20;- Print each runner with their bib number, like: Bib 101: Alice

&#x20;- Using a list comprehension, create a new list containing only the bib numbers (as integers) for runners whose name has more than 5 letters.

&#x20;- Print that filtered list.



Bonus: print how many runners qualified for the "long name club" (i.e., the length of the filtered list).
