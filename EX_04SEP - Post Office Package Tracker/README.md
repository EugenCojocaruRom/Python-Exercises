EX\_04SEP - Post Office Package Tracker



Task:

Ask the user how many packages are being processed today. For each package, collect the recipient's name and the package weight (in kg).



Then:

&#x20;- Print a numbered list of all packages using enumerate() (e.g. 1. Maria — 3.5 kg)

&#x20;- Use a list comprehension to find all "heavy" packages — anything over 5 kg — and print how many there are (with singular/plural handling: "1 heavy package" vs "3 heavy packages")

&#x20;- Calculate and print the total weight and the average weight of all packages

&#x20;- Find the heaviest package and print who it belongs to (handle a tie if two people have the same max weight)



Bonus (optional): Add a shipping cost calculator — €2 base fee, plus €0.75 per kg over 5kg — and print each recipient's cost alongside their package info.
