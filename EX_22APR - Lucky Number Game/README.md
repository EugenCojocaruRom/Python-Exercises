EX\_22APR - Lucky Number Game

Write a program that does the following:

&#x20;- Setup — these are the "winning numbers" for the week: e.g. winning\_numbers = \[4, 17, 23, 8, 42, 15]

The user enters 5 numbers one by one (use input() in a loop). Then your program:

&#x20;- Build the list of numbers the user entered (converting each to int as you collect them).

&#x20;- Count how many of the user's numbers match the winning numbers.

&#x20;- Print a result based on how many they matched:

&#x09;-> 0 matches → "No matched numbers! Better luck next time!"

&#x09;-> 1–2 matches → "Not bad, you matched X numbers!"

&#x09;-> 3–4 matches → "Nice job! X matches — so close!"

&#x09;-> 5 matches → "JACKPOT! You got them all!"
