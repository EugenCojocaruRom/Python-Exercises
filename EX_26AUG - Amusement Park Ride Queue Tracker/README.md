EX\_26AUG - Amusement Park Ride Queue Tracker

Write a program that tracks riders waiting in line for a ride.



&#x20;- Ask the user how many riders are in the queue (validate it's a positive number).

&#x20;- For each rider, ask for their name and how many minutes they've been waiting.

&#x20;- Store each entry as a tuple (or however you like) in a list.

&#x20;- Print the queue using enumerate(), numbered starting at 1 — e.g. 1. Maria - waited 12 minutes.

&#x20;- Use a list comprehension to build a list of riders who've waited 15 minutes or longer, and print them with correct singular/plural/zero messaging (e.g. "1 rider has waited 15+ minutes" vs "3 riders have waited...").

&#x20;- Calculate and print the average wait time for the whole queue.



Optional bonus:

&#x20;- Find the rider who's waited the longest, handling ties (multiple riders with the same max wait).

&#x20;- A "fast pass" flag: any rider who's waited over 30 minutes automatically gets moved to the front — print an updated queue order reflecting that.
