EX\_02SEP - Yoga Studio Class Pass Tracker

The task:



&#x20;- Ask the user how many class check-ins to record.

&#x20;- For each check-in, collect:

&#x09;Member name

&#x09;Class type (e.g. "Vinyasa", "Restorative", "Power Yoga")

&#x09;Class duration in minutes

&#x20;- Store each check-in as a tuple, and store all check-ins in a list.

&#x20;- Using enumerate() (starting at 1), print a numbered list of all check-ins in the format:

&#x09;1. Elena — Vinyasa (60 min)

&#x20;- Calculate and print the total minutes practiced across all check-ins.

&#x20;- Using a list comprehension, filter and print all check-ins longer than 75 minutes ("long sessions"), with correct singular/plural/zero wording (e.g. "1 long session" vs. "3 long sessions" vs. "No long sessions today").

&#x20;- Find the longest session (handle ties — if two members tie for longest, show both).



Bonus (optional):

&#x20;- Build a dictionary aggregating total minutes practiced per class type, then print a leaderboard sorted from most to least popular class type using sorted().
