EX\_08MAY - Garden Planning Calculator

Create a program that helps organize the community garden by processing three planning numbers.

Read three integers, then:

&#x20;- find the closest prime number to the first (for plot assignments)

&#x20;- calculate the sum-product of the second number's digits (sum all digits, then multiply that sum by itself)

&#x20;- check if the third number is between 10 and 20 inclusive (print "YES" or "NO" for ideal planting range).
