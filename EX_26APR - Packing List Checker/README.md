EX\_26APR - Packing List Checker

You're going on a trip. You have a master packing list and a bag with what you've actually packed so far.

Write a program that:

&#x20;- Finds what you forgot (in must\_pack but not in in\_bag)

&#x20;- Finds what you packed but don't actually need (in in\_bag but not in must\_pack)

&#x20;- Prints a packing score: how many essential items you got out of the total, e.g. "You packed 4/7 essentials"

&#x20;- If you forgot nothing, prints "You're all set, enjoy your trip!", otherwise lists the forgotten items
