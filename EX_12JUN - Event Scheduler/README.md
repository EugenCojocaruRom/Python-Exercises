EX\_12JUN - Event Scheduler

You're building a simple personal event scheduler.

Your program should:

&#x20;- Have a list of event names (at least 4 — things like "Dentist", "Birthday Party", "Gym", "Team Meeting")

&#x20;- Use a loop + input() to ask the user to enter a day of the week for each event

&#x20;- Store the results as a list of tuples like ("Dentist", "Monday")

&#x20;- Use enumerate() to print a numbered schedule of all events

&#x20;- Use list comprehension to show only the events scheduled for a specific day the user picks at the end
