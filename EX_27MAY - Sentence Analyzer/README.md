EX\_27MAY - Sentence analyzer

Write a function analyze\_sentence(sentence) that takes a string and returns a dictionary with these stats:

&#x20;- "words" -> list of words (lowercase, no punctuation)

&#x20;- "word\_count" -> total number of words

&#x20;- "longest\_word" -> the longest word (first one if tie)

&#x20;- "starts\_with\_vowel" -> list of words that start with a vowel

&#x20;- "word\_lengths" -> list of (word, length) tuples, built with a list comprehension

&#x20;- "most\_common\_letter" -> the most frequent letter (ignore spaces and punctuation)
