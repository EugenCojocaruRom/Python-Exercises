EX\_19MAY - Party guest list

You're organizing a party and need to manage the guest list. Write a program that does the following:

&#x20;- You have a list of guests who RSVP'd yes

&#x20;- Some guests cancelled last minute

&#x20;- Using a list comprehension, create a list of guests who are actually coming (i.e. not in cancelled).

&#x20;- Loop through the confirmed guests and print a welcome message for each one. But:

&#x20;  -> If the guest's name has more than 5 letters, print: "Welcome, \[name]! We saved you a special seat."

&#x20;  -> Otherwise, print: "Hey \[name], glad you could make it!"

&#x20;- At the end, print the total number of confirmed guests.
