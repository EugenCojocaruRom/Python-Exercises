EX\_25JUN - Habit Tracker

You're tracking daily habits over a week. Each habit has a name and a list of 7 booleans (True/False) for whether you did it each day.

&#x20;- Store data as a list of tuples: (habit\_name, \[True, False, True, ...]) — 7 days each

&#x20;- For each habit, use a list comprehension (or sum()) to count how many days it was completed, and print it like:

&#x20;  Drink water       : 6/7 days ✅

&#x20;  Read 10 pages     : 3/7 days

&#x20;- Use enumerate() to find and print the best day of the week overall — the day with the most habits completed across all habits

&#x20;- Calculate each habit's completion rate as a percentage (rounded)

Bonus: find the habit with the longest current "streak" (consecutive Trues counting back from day 7)
