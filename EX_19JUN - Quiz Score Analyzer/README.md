EX\_19JUN - Quiz Score Analyzer

The idea: a teacher wants to enter scores for all students who took a quiz, and get a quick breakdown of how the class did.

Tasks:

&#x20;- Ask the user how many students took the quiz

&#x20;- For each student, collect their name and their score (out of 100), using a loop — enumerate() could come in handy for numbering the prompts

&#x20;- Calculate the class average score

&#x20;- For each student, indicate whether they're above, below, or exactly at the class average

&#x20;- Find and print the name of the student with the highest score (think max() with a lambda key, like you did in the Leaderboard exercise)

Extra tasks:

&#x20;- Use a list comprehension to build a list of just the students who scored above average

&#x20;- Sort students from highest to lowest score before printing the final summary

&#x20;- Add a simple letter grade for each student (A/B/C/D/F) based on their score

&#x20;- Handle invalid input (e.g. someone typing a score over 100 or a non-numeric value) with try/except
