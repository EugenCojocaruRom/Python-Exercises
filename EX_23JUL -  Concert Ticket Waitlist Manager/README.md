EX\_23JUL - Concert Ticket Waitlist Manager

A small venue is managing a waitlist for a sold-out concert. You'll track people signing up, and process how many tickets become available.

Each tuple is (name, number\_of\_tickets\_requested).



Requirements:

&#x20;- Print the waitlist using enumerate() (starting at 1), in the format: Position 1: Alex - 2 ticket(s)

&#x20;- Calculate and print the total number of tickets requested across everyone on the list

&#x20;- Given that available\_tickets = 6, go through the waitlist in order and figure out who gets tickets — a person is served only if there are enough remaining tickets for their full request (no partial fulfillment). Print who got tickets and who didn't.

&#x20;- Using a list comprehension, build a list of names who requested more than 2 tickets



Bonus: print how many tickets are left over after processing the waitlist in step 3
