EX\_19AUG - Skate Park Session Tracker



Tasks:

&#x20;- Ask the user how many skaters checked in today.

&#x20;- For each skater, collect their name and how many minutes they skated. Store each as a tuple, and build a list of all sessions.

&#x20;- Print a numbered list of all sessions using enumerate() (start at 1)

&#x20;- Calculate the total minutes skated by everyone combined.

&#x20;- Use a list comprehension to build a list of skaters who skated more than 30 minutes — call them "Long Session" skaters — and print how many there are (handle the case where there are none, one, or several — singular/plural wording).

&#x20;- Find and print the skater with the longest session (use max() with a lambda).



Bonus (optional): add an average session length calculation, and print how many skaters were below that average.
