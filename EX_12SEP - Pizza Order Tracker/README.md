EX\_12SEP - Pizza Order Tracker

Write a program that:



&#x20;- Asks the user for the number of orders to process.

&#x20;- For each order, reads: the customer's name, the pizza size (Small/Medium/Large), and the number of slices eaten.

&#x20;- Stores each order as a tuple (name, size, slices) in a list.

&#x20;- Displays all orders using enumerate() (starting at 1), formatted like: 1. Ana - Medium - 6 slices

&#x20;- Calculates and displays the total number of slices eaten (using sum() with a generator or list comprehension).

&#x20;- Using a list comprehension, builds a list of only the orders where the customer ate more than 8 slices, and displays it (with singular/plural/zero handling, like you've done in previous exercises).



Bonus (optional):

&#x20;- Find the order with the most slices eaten (using max() + lambda).

&#x20;- Build a dictionary with the total slices eaten per pizza size (Small/Medium/Large).
