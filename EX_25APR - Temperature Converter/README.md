EX\_25APR - Temperature Converter

Write a program that:

&#x20;- Has a list of temperatures in Celsius: e.g. \[0, 20, 37, 100, -15, 25, 42]

&#x20;- Converts them all to Fahrenheit

&#x09;-> Formula: F = C \* 9/5 + 32

&#x20;- Loops through both lists together and prints each pair, e.g. 0°C = 32.0°F

&#x20;- At the end, prints:

&#x09;-> The hottest Fahrenheit temperature

&#x09;-> The coldest Fahrenheit temperature

&#x09;-> How many temperatures are above 70°F
