EX\_25APR - Playlist duration formatter

You have a list of songs, each represented as a tuple of (title, duration\_in\_seconds).

Tasks:

&#x20;- Filter out any songs shorter than 2 minutes (they're intros/outros, ignore them)

&#x20;- Calculate the total duration of the remaining songs

&#x20;- Format the total as Xh Ym Zs

&#x20;- Print a numbered tracklist with each song's duration formatted as M:SS

&#x20;- Find the longest song and print it at the end
