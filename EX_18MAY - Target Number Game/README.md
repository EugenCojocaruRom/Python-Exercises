EX\_18MAY - Target number game

Write a program that generates a list of random numbers, then lets the user guess which numbers in the list add up to a target number.

Specifically:

&#x20;- Create a list of 10 random integers between 1 and 20

&#x20;- Pick a random target number (between 10 and 40)

&#x20;- Display the list and the target to the user

&#x20;- Ask the user to input two numbers from the list that they think add up to the target

&#x20;- Check if both numbers exist in the list and if they sum to the target

&#x20;- Print a win/lose message accordingly
