EX\_24MAY - Playlist Shuffler \& Stats

You have a list of songs (just strings). Write a program that:

&#x20;- Slices the playlist to get only the first half of songs

&#x20;- Reverses the second half and appends it to the first half (making a "mirrored" playlist)

&#x20;- Uses list comprehension to create a new list of songs that have more than 4 characters in their name

&#x20;- Uses enumerate() to print the final playlist with track numbers starting from 1

&#x20;- Prints how many songs were filtered out in step 3
