EX\_09JUL - Sock Drawer Pair Matcher

You pull socks out of a drawer one at a time (given as a list of colors, e.g. \["red", "blue", "red", "green", "blue", "red"]). Write a program that:

&#x20;- Figures out how many complete pairs you can make.

&#x20;- Lists which colors have leftover (unpaired) socks.

&#x20;- Uses enumerate() somewhere to report which pull number each sock came from (e.g. "sock #3 was blue").

&#x20;- Uses a list comprehension at least once — for example, to build the list of colors that have an odd count.
