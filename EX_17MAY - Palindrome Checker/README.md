EX\_17MAY - Palindrome checker

Write a program that takes a list of words and uses a list comprehension to find which ones are palindromes (words that read the same forwards and backwards).

Requirements:

&#x20;- Start with a list of words, e.g. \["racecar", "hello", "level", "world", "madam", "python", "civic"]

&#x20;- Use a list comprehension to create a new list containing only the palindromes

&#x20;- Print each palindrome with a message like: "racecar" is a palindrome!

&#x20;- At the end, print how many palindromes were found
