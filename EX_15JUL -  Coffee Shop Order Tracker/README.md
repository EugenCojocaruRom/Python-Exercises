EX\_15JUL - Coffee Shop Order Tracker

Write a program that manages a coffee shop's orders during a morning rush.



Requirements:

&#x20;- Ask the user how many orders to enter, then collect that many orders — each order should include a customer name and a drink name (dynamic input, not hardcoded).

&#x20;- Store the orders as a list of tuples: (customer\_name, drink\_name).

&#x20;- Print a numbered order list (starting from 1) in this format:



&#x20;  Order #1: Maria - Cappuccino

&#x20;  Order #2: Andrei - Latte



&#x20;- After all orders are in, print a drink summary showing how many times each drink was ordered, e.g.:



&#x20;  Cappuccino: 2

&#x20;  Latte: 1



&#x20;- Print which drink was the most popular this morning.



Bonus: using a list comprehension, print only the customers who ordered a specific drink (ask the user which drink to filter by).
