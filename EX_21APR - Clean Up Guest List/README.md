EX\_21APR - Clean Up a Guest List

You have a messy guest list with some problems:

&#x20;- Some names have extra spaces (e.g. "  Alice ")

&#x20;- Some names are duplicates

&#x20;- Some entries are not real names — they're just numbers (e.g. "42")

Tasks:

&#x20;- Strip the whitespace from each name

&#x20;- Filter out any "names" that are just numbers

&#x20;- Deduplicate the list (case-insensitive — "Alice" and "alice" are the same person)

&#x20;- Print the final clean guest list, with each name properly capitalized
