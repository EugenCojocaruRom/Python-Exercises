EX\_17SEP - Fruit Basket Counter



You're given a fixed list representing fruits in a basket (with duplicates):



&#x09;basket = \["apple", "banana", "apple", "mango", "banana", "apple", "kiwi", "mango", "apple"]



Write a program that:

&#x20;- Uses enumerate(start=1) to print each fruit with its position number, e.g. 1. apple

&#x20;- Uses a list comprehension to build a list of only the fruits with more than 4 letters

&#x20;- Builds a dictionary counting how many times each fruit appears in the basket



Bonus: print a leaderboard of fruits sorted by count, descending (most common first), with each line showing the fruit and its count
