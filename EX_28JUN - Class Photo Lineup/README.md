EX\_28JUN - Class Photo Lineup

You're organizing a class photo and need to arrange students by height for the photo (shortest in front, tallest in back), but also want to print a numbered list for the teacher.

Requirements:

&#x20;- Start with a list of tuples, e.g. students = \[("Mara", 142), ("Andrei", 156), ("Ioana", 138), ("Vlad", 161), ("Sofia", 145)]

&#x20;- Sort the students by height (shortest to tallest).

&#x20;- Use enumerate() to print a numbered list, e.g.:



&#x20;  1. Ioana - 138 cm

&#x20;  2. Mara - 142 cm

&#x20;  3. Sofia - 145 cm



&#x20;- Use a list comprehension to create a new list containing only the names of students taller than 150 cm.

&#x20;- Print that list with a friendly message, like: "Students taller than 150cm: \['Andrei', 'Vlad']"



Bonus (optional):

&#x20;- Calculate and print the average height of the group.

&#x20;- Add a feature where the user can input a new student's name and height, insert them into the correct sorted position, and reprint the lineup.
