EX\_01APR - BMI Calculator

Define a function 'bmi()' that takes 2 arguments, weight and height, and calculates the Body Mass Index based on the values entered by the user.

The BMI formula is "weight / (height \* height)".

Display the BMI value and possible body types depending on the resulting BMI values, e.g.:

&#x20;- BMI < 18.5 - underweight

&#x20;- BMI < 25 - normal weight

&#x20;- BMI < 30 - overweight

&#x20;- BMI > 30 - obese
