EX\_13MAY - Museum Setup Assistant

Create a program that helps prepare a museum exhibition by handling three tasks:

&#x20;- generate a simple password from the exhibition name (using just the first 3 characters)

&#x20;- find the largest display case size from a list of numbers

&#x20;- determine the ticket price based on a visitor's age.

For the password, take the first 3 characters of the exhibition name and convert them to uppercase.

Ticket prices are: $5 for children under 12, $8 for ages 12-17 and 65+, and $12 for adults 18-64.
