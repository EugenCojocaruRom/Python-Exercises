EX\_25AUG - Dog Walking Service Tracker

The task:

A dog walking service wants to track their walks for the day.



&#x20;- Ask the user how many walks happened today (validate it's a positive number).

&#x20;- For each walk, collect:

&#x09;the dog's name

&#x09;the walk duration in minutes

&#x20;- Store each walk as a tuple: (dog\_name, duration).

&#x20;- Print a numbered list of all walks using enumerate() starting at 1, e.g.:

&#x20;  Walk #1: Rex - 30 minutes

&#x20;  Walk #2: Bella - 45 minutes

&#x20;- Use a list comprehension to build a list of dogs that had a "long walk" (over 40 minutes).

&#x20;- Print how many long walks there were, with proper singular/plural handling ("1 long walk" vs "3 long walks").

&#x20;- Calculate and print the total minutes walked across all dogs (you can use sum() here).



Bonus (optional):

&#x20;- Build a dictionary aggregating total minutes walked per dog (in case the same dog is walked more than once), then print a leaderboard sorted by total minutes, descending
