EX\_23APR - Dice Roll Simulator

Write a program that:

&#x20;- Simulates 10 dice rolls and stores the results in a list.

&#x20;- Prints all the rolls in one line, e.g. Rolls: \[3, 1, 6, 2, 6, 4, 1, 5, 3, 6]

&#x20;- Count how many times each number (1–6) appeared and print it

&#x20;- Prints the highest and lowest roll — but without using max() or min(), find them manually in a loop with if statements.
