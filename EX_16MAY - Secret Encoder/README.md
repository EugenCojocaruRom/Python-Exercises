EX\_16MAY - The Secret Encoder

Write a program that takes a sentence and encodes it by:

&#x20;- Splitting the sentence into a list of words

&#x20;- Using a list comprehension to reverse each word individually (so "hello" becomes "olleh")

&#x20;- Only keeping words that are longer than 3 letters (filter this in the same list comprehension)

&#x20;- Joining the reversed words back into a single string and printing it
