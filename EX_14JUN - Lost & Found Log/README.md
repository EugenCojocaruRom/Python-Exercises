EX\_14JUN - Lost \& Found Box

You're managing a lost \& found box at a train station. The box contains a list of items, each represented as a tuple: (item\_name, days\_in\_box, claimed) where claimed is a boolean.

Tasks:

&#x20;- Print all items with their index (using enumerate()), showing the name and how many days they've been in the box.

&#x20;- Use a list comprehension to get a list of only the unclaimed items that have been in the box more than 3 days — these are "overdue".

&#x20;- Find the item that has been in the box the longest (claimed or not).

&#x20;- Count how many items are claimed.

&#x20;- Print a short summary at the end.
