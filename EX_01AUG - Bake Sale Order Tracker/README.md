EX\_01AUG - Bake Sale Order Tracker

A local bake sale wants a simple tool to log orders as they come in and get a quick end-of-day summary.



Requirements:

&#x20;- Ask the user to enter orders one at a time — each order has an item name and a price. Use a loop that keeps asking until the user types something like 'done' to stop.

&#x20;- Store each order as a tuple (or however you like) in a list.

&#x20;- After input ends, print a numbered receipt of all orders using enumerate() (starting at 1).

&#x20;- Calculate and print the total revenue from all orders.

&#x20;- Use a list comprehension to find all orders priced above $5 (call them "premium items") and print them.

&#x20;- Print how many premium items were sold, with correct singular/plural wording ("1 premium item" vs "3 premium items").



Bonus (optional): find the single most expensive item sold using max() with a lambda.
