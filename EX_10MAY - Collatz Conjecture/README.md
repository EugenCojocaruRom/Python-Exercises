EX\_10MAY - Collatz Conjecture

Pick any positive number. If it's even, divide it by 2. If it's odd, multiply by 3 and add 1. Repeat until you reach 1.

Tasks:

&#x20;- Write a loop that applies the rule until the number hits 1

&#x20;- Print each step of the sequence

&#x20;- Count how many steps it took

&#x20;- Bonus: Ask the user for the starting number with input()

&#x20;- Bonus 2: Try a few different starting numbers — which one takes the longest to reach 1? Store the results in a list of tuples like (starting\_number, steps) and print the "champion"
