EX\_06SEP - Pangram Checker

A pangram is a sentence that uses every letter of the alphabet at least once (e.g. "The quick brown fox jumps over the lazy dog").



Requirements:

&#x20;- Ask the user to input a sentence.

&#x20;- Normalize it (lowercase, ignore spaces/punctuation).

&#x20;- Check whether it's a pangram — i.e. all 26 letters appear at least once.

&#x20;- Print a clear result: pangram or not.



Bonus ideas (optional):

&#x20;- If it's not a pangram, list which letters are missing.

&#x20;- Use enumerate() to print each missing letter with a number (e.g. "1. e", "2. q"...).

&#x20;- Use a list comprehension to count how many times each letter of the alphabet appears in the sentence, and print only the letters that appear more than 3 times.

&#x20;- Handle multiple sentences in a loop (while-True with a "done" sentinel to stop), and report which sentence used the fewest unique letters.
