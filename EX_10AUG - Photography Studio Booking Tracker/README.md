EX\_10AUG - Photography Studio Booking Tracker



Tasks:

&#x20;- Ask the user how many bookings there are.

&#x20;- For each booking, collect:

&#x09;client name

&#x09;session type (e.g. "Portrait", "Wedding", "Product")

&#x09;duration in minutes

&#x09;price (a number)

&#x20;- Store each booking as a tuple in a list.

&#x20;- Print a numbered summary of all bookings using enumerate() (start at 1)

&#x20;- Using a list comprehension, calculate the total revenue for the day.

&#x20;- Using another list comprehension, find all bookings longer than 60 minutes and print them with proper singular/plural handling ("1 long session" vs "3 long sessions").

&#x20;- Use max() with a lambda to find the most expensive booking — remember to guard against an empty list.



Bonus (optional):

&#x20;- Aggregate total revenue per session type into a dictionary, then print a little leaderboard sorted by revenue, descending (highest-earning session type first).
