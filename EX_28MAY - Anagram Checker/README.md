EX\_28MAY - Anagram checker

Write a function are\_anagrams(word1, word2) that checks whether two words are anagrams of each other (same letters, different order — e.g. "listen" and "silent").

Requirements:

&#x20;- Ignore case ("Listen" and "Silent" should still match)

&#x20;- Use a list comprehension to get the sorted list of characters from each word

&#x20;- Use enumerate() somewhere — for example, to print a numbered comparison of the two words' sorted letters side by side
