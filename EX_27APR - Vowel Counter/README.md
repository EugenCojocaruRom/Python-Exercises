EX\_27APR - Vowel Counter

Write a program that:

&#x20;- Has a list of words: e.g. \["apple", "rhythm", "orange", "sky", "umbrella", "gym", "elephant"]

&#x20;- Uses a list comprehension to create a new list with the count of vowels in each word

&#x20;- Loops through both lists together and prints each word with its vowel count

&#x20;- Uses an if/else to label each word as "vowel-rich" (3 or more vowels) or "vowel-poor" (fewer than 3)
