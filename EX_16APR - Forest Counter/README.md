EX\_16APR - Forest Counter

You have a list of animals spotted during a nature walk. Your job is to analyze the sightings.

1\. Use a list comprehension to get a new list with only the birds (they're marked with a "b" in the tuple, and the mammals with "m").

2\. Print how many birds were spotted.

3\. Loop through all the animals and print each one — if the same animal appears more than once in the list, add "(seen before!)" next to it.
