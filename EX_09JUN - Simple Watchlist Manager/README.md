EX\_09JUN - Simple Watchlist Manager

You have a list of movies, each stored as a tuple: (title, year, watched) where watched is True or False.

Tasks:

&#x20;- Print a numbered list of all movies (use enumerate()) showing title, year, and whether it's been watched or not.

&#x20;- Use a list comprehension to create a list of only the unwatched movies (just their titles).

&#x20;- Print how many movies are unwatched.

&#x20;- Find and print the oldest movie in the list (by year).
