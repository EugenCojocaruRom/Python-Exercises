EX\_14MAY - Coin Flip Streak Tracker

Write a program that simulates flipping a coin 20 times and tracks the results.

Requirements:

&#x20;- Create a list of 20 random coin flips, where each flip is either "H" (heads) or "T" (tails) -> use list comprehension

&#x20;- Print the full sequence of flips on one line, e.g.: H T H H T T H ...

&#x20;- Count and print how many Heads and Tails you got.

&#x20;- Find and print the longest streak of the same result in a row (e.g. H H H H = streak of 4).
