EX\_15APR - Grade Analyzer

Write a program that takes the students' scores (0–100) and:

&#x20;- finds the highest and lowest score without using min() or max()

&#x20;- creates a list called 'passed' that contains only scores above 60

&#x20;- assigns a letter grade to each score and prints them, e.g.:

&#x09;90–100 -> A

&#x09;80–89 -> B

&#x09;70–79 -> C

&#x09;60–69 -> D

&#x09;Below 60 -> F
