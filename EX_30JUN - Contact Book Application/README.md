EX\_30JUN - Contact Book Application

Build a Contact Book application. Create functions for displaying the menu, add contact, view contact, edit contact, delete contact, list all contacts.



Tasks:

&#x20;- Combine the functions created:

&#x20;       display\_menu: Displays the menu options for the user.

&#x20;       add\_contact: Adds a new contact to the Contact Book.

&#x20;       view\_contact: Displays details for a specific contact.

&#x20;       edit\_contact: Updates an existing contact's information.

&#x20;       delete\_contact: Removes a contact from the Contact Book.

&#x20;       list\_all\_contacts: Displays all the contacts in the Contact Book.

&#x20;- Create a dictionary called contact\_book to store the contacts.

&#x20;- Write a loop that:

&#x20;       Displays the menu using display\_menu.

&#x20;       Accepts user input for the menu choice.

&#x20;       Calls the appropriate function based on the user's choice.

&#x20;       Prints "Invalid choice. Please try again." if the user enters a choice that is not one of the valid menu options.

&#x20;       Continues until the user selects the option to exit the program.



Expected Behavior - when you run the program, it should:

&#x20;- Show a menu of options for the user to choose from.

&#x20;- Allow the user to interact with the Contact Book by calling the appropriate function.

&#x20;- Print Invalid choice. Please try again. when the user enters an unrecognized option.

&#x20;- Exit the program cleanly when the user selects the "Exit" option.
