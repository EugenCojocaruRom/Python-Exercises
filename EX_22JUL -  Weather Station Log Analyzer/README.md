EX\_22JUL - Weather Station Log Analyzer

You have a weekly weather log with daily temperature records, as a list of tuples (day, temperature).



Requirements:

&#x20;- Print the entire log using enumerate() (starting at 1), in the format: Day 1: Monday - 18°C

&#x20;- Calculate and print the week's average temperature

&#x20;- Using a list comprehension, build a list of only the days where the temperature was above 24°C (just the day names, not the full tuple)

&#x20;- Find the hottest day and the coldest day (name + temperature) — you can use max()/min() with lambda



Bonus: count how many days had a temperature below the week's average, also using a list comprehension
