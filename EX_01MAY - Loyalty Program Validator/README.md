EX\_01MAY - Loyalty Program Validator

Create a program that validates customer information for a loyalty program.

Read a username, an account balance, and the customer's position in the queue.

Tasks:

&#x20;- Check if the username is valid (3-15 characters, letters/numbers/underscores only, can't start with a number)

&#x20;- Verify the balance is a valid decimal number

&#x20;- Calculate the estimated wait time (5 minutes per customer ahead in queue).

&#x20;- Print "Valid" or "Invalid" for each check, followed by the wait time in minutes.
