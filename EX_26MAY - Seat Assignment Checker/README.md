EX\_26MAY - Seat assignment checker

At a movie theater, you have a list of seats in a row, some taken, some free.

Tasks:

&#x20;- Use list comprehension to create a list of seat numbers (1-indexed) that are free.

&#x20;- Use enumerate() to print each seat with its status (e.g. Seat 1: taken, Seat 2: free)

&#x20;- Find pairs of adjacent free seats (two free seats next to each other) and print their seat numbers. A couple wants to sit together!

&#x20;- If no adjacent free seats exist, print "Sorry, no seats for couples!" — otherwise print how many pairs were found.
