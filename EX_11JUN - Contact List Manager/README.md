EX\_11JUN - Contact List Manager

Create a simple interactive program that runs in a loop and manages a contact list.

The program should:

&#x20;- Show a menu with options: add / search / list / quit

&#x20;- list — use enumerate() to print all contacts numbered

&#x20;- search — ask for a name, use a list comprehension to find matches (partial match counts!)

&#x20;- add — ask for name, email, phone and append to the list

&#x20;- quit — print how many contacts are in the list and exit
