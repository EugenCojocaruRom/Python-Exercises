EX\_14JUL - Scrabble Score Calculator

Given a list of words, calculate each word's Scrabble score based on standard letter values, then show the results with their ranking.



Requirements:

&#x20;- Use a letter value dictionary (standard Scrabble values)

&#x20;- Ask the user to input several words (your choice — comma-separated, or a loop until they type "done", whatever feels natural).

&#x20;- Calculate the score for each word (sum of its letters' values).

&#x20;- Print each word with its score, numbered (this is a good spot for enumerate()).

&#x20;- Find and display the highest-scoring word.



Bonus: sort and display all words from highest to lowest score.
