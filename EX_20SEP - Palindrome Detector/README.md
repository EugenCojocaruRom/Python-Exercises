Requirements:

&#x20;- Ignore case (e.g., "Anna" should be recognized as a palindrome).

&#x20;- Display the results using enumerate()



Bonus: also show how many letters each palindrome has.



words = \["level", "table", "Anna", "radar", "python", "civic", "kayak"]
