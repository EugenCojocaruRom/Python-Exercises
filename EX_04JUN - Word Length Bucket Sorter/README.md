EX\_04JUN - Word Length Bucket Sorter

Write a function called bucket\_sort\_words that takes a list of words and groups them by their length.

The function should return a dictionary where:

&#x20;- each key is a word length (a number)

&#x20;- each value is a list of words that have that length

Requirements:

&#x20;- Use a for loop (or list comprehension)

&#x20;- The dictionary keys should appear in sorted order when you print the result

&#x20;- Words of the same length should appear in the order they were in the original list

As a bonus: print the result in a readable way, e.g.:

&#x20;> Length 2: hi, be

&#x20;> Length 3: cat, dog, fox
