EX\_24SEP - Book Inventory Duplicate Finder

You have a list of book titles borrowed from a small library shelf (with possible duplicates, different casing). Write a program that:

&#x20;- Stores the list of book titles (at least 8, include a few duplicates with mixed casing, e.g. "Dune" and "dune").

&#x20;- Uses list comprehension to normalize all titles to lowercase.

&#x20;- Uses enumerate() to print each title with its original position (starting at 1), like:

&#x20;  1. Dune

&#x20;  2. 1984

&#x20;  3. dune

&#x20;  ...

&#x20;- Finds and prints which titles are duplicates (case-insensitive), without printing the same duplicate twice.

&#x20;- Prints the total number of unique titles.



Bonus (optional): Count how many times each title appears (case-insensitive) and print it as a small report, sorted from most to least frequent.
