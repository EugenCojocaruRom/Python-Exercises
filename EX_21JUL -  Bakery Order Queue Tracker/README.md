EX\_21JUL - Bakery Order Queue Tracker

You're tracking orders at a small bakery. Each order is a tuple: (customer\_name, item, quantity, price\_per\_item).



Requirements:

&#x20;- Print a numbered order queue (order #1, #2, ...) showing customer, item, quantity, and the line total (quantity × price), using enumerate().

&#x20;- Calculate and print the total revenue for the day.

&#x20;- Using a list comprehension, find all orders where quantity ≥ 3 (the "bulk orders").

&#x20;- Find which single item generated the most revenue overall (hint: you'll want a dictionary to add up revenue per item name, since the same item shows up in multiple orders).

&#x20;- Print the average order value for the day.



Bonus (optional): Let the user add a new order via input (name, item, quantity, price), append it to the list, and recalculate everything.
