EX\_29JUN - Locker Assignment Checker

A school has a row of lockers numbered 1 to N. Students are assigned lockers based on a simple rule, but the office wants a program to double-check things and report useful info.

Requirements:

&#x20;- Ask the user how many lockers there are (N).

&#x20;- Ask the user to input a list of student names (comma-separated is fine).

&#x20;- Assign each student to a locker number using enumerate() — student 1 gets locker 1, student 2 gets locker 2, etc.

&#x20;- Print out the full assignment list, nicely formatted/aligned.

&#x20;- Using list comprehension, find and print all locker numbers that are multiples of 3 (these lockers are next to the windows — a nice perk).

&#x20;- If there are more students than lockers, print a warning message instead of crashing.



Bonus (optional):

&#x20;- Let the user also input a list of "broken" locker numbers, and skip those when assigning (so a student would get the next available locker instead).

&#x20;- Print which students ended up with a "window locker."
