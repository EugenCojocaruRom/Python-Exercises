EX\_18JUL - Road Race Pace Calculator

You have a list of runners with their name and finish time (in minutes).



Write a program that:

&#x20;- Stores runners as a list of tuples: ("Ana", 42.5), ("Mihai", 38.0), etc.

&#x20;- Using enumerate() (starting at 1), print each runner's rank in finish order, their name, and their pace in minutes per km (pace = time / race length).

&#x20;- Use a list comprehension to build a new list containing only the names of runners who finished under 40 minutes.

&#x20;- Print the fastest and slowest runner (name + time) using min()/max() with a lambda.



Bonus: ask the user to input a "target time" and count how many runners beat it.
