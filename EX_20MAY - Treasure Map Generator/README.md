EX\_19MAY - Treasure Map Generator

You have a grid of size N×N. Some cells contain treasure ($), some are empty (.), and one is your starting position (@).

Write a program that:

&#x20;- Creates a 5×5 grid filled with .

&#x20;- Places @ at position (0, 0)

&#x20;- Randomly places 5 treasures ($) at different positions (not on @)

&#x20;- Prints the grid nicely

&#x20;- Uses a list comprehension to collect all treasure coordinates as (row, col) tuples

&#x20;- Uses enumerate() to print each treasure's location like:

&#x20;   -> Treasure 1 is at row 2, col 4

&#x20;   -> Treasure 2 is at row 3, col 1
